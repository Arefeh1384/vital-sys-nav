# تفکیک ریسک‌های بیمارستان مرکزی — نسخه آزمایشی

این بسته روی اصلاحیه Supply-Demo-Per-Hospital ساخته شده است؛ اگر فایل فعلی متفاوت است، ابتدا مقایسه کنید.

## اعمال
1. دو فایل زیر را فقط پس از بررسی تغییرات جایگزین کنید:
   - src/him/supply/store.ts
   - src/him/supply/SupplyViews.tsx
2. برای افزودن «بیمارستان مرکزی (آزمایشی)» به انتخاب مراکز، در ریشه پروژه:
   `git apply --check central-site-mockData.patch`
   سپس در صورت موفقیت:
   `git apply central-site-mockData.patch`
3. `npm run build` و `npm run test` را اجرا کنید.

## رفتار
- مرکز جدید SITE-CENTRAL-DEMO با siteId یکتا برای داده‌های قدیمی مرکزی تعریف می‌شود.
- سه ریسک قدیمی RISK-1001 تا RISK-1003 فقط در بیمارستان مرکزی آزمایشی دیده می‌شوند.
- برای چهار بیمارستان دیگر، داده‌های نمایشی مستقل قبلی باقی می‌مانند.
- در «ستاد مرکزی دانشگاه» هیچ ریسک بیمارستان مرکزی نمایش داده نمی‌شود؛ ستاد بیمارستان نیست.
- امکان نمایش همه ریسک‌ها به‌صورت غیرمنتسب حذف شده است.
- این‌ها فیکسچر آزمایشی‌اند، نه داده واقعی بیمارستان‌ها.

این بسته منتشر نشده و تست مرورگری/Build کامل این نسخه انجام نشده است. در صورت شکست git apply، mockData را دستی تغییر ندهید و فایل فعلی را برای مقایسه ارسال کنید.
